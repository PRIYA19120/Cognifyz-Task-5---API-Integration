# Cognifyz Task 5 - API Integration

## About the Project
This project is part of my Front-End Development Internship at Cognifyz Technologies.

## Objective
To fetch data from a public API and dynamically display it on a webpage.

## Features
- Fetches sample posts from JSONPlaceholder
- Displays post titles and descriptions
- Dynamically creates post cards
- Refresh button to fetch posts again
- Loading and error messages
- Responsive card layout

## Technologies Used
- HTML5
- CSS3
- JavaScript Fetch API
- JSONPlaceholder API

## How to Run
1. Open the project in VS Code.
2. Run `index.html` using Live Server.
3. Ensure an internet connection is available.
4. Click the Refresh Posts button to fetch the data again.

## Learning Outcome
I learned how to make API requests using `fetch()`, parse JSON responses, handle errors, and dynamically update webpage content.
